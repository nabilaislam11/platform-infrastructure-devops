# Contribution and Review Guide

This repository is a personal, independently maintained engineering portfolio.

## Contribution expectations

- Submit independently written, technically verifiable content.
- Use generic lab placeholders, not real infrastructure identifiers.
- Distinguish tested results from illustrative procedures or proposed experiments.
- For operational changes, include prerequisites, risk assessment, verification, and recovery.
- Prefer vendor documentation and primary technical references.
- Avoid credentials, proprietary code, internal diagrams, real incident details, screenshots, and unapproved logs.

## Review checklist

1. Confirm technical correctness and supported OS/tool versions.
2. Verify commands do not imply unsafe production execution.
3. Check that examples contain no sensitive employer information.
4. Run `python3 scripts/validate_repository.py` and review all warnings.
5. Check external reference URLs manually; the script does not verify live websites.
6. Check formatting, terminology, and evidence claims.
7. Obtain explicit approval before replacing existing repository files.

This repository is not an official employer support channel.
